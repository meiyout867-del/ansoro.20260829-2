募集要項

参加条件

  • 二次創作・同人活動に関するマナーを理解していること
  • 本アンソロジーの趣旨を理解し、募集要項にすべて同意していただけること
  • 締切までに原稿を提出できること
  • 連絡可能なメールアドレスを所持していること

原稿規定

  • 公募制
  • 未発表作品（SNS、pixiv、個人サイト、同人誌等で全文または完成版を公開していない作品）
  • 全年齢対象
  • A5サイズ、右綴じ
  • ①漫画②小説③イラスト（モノクロのみ）④短歌 / 俳句 / 川柳
    形式が異なれば複数作品で参加可能です。短歌 / 俳句 / 川柳は合わせて一形式です
    OK：①漫画④短歌
    NG：①漫画①漫画
    NG：④短歌④俳句
  • 複数作品応募される方は、作品数分応募フォームをご入力ください
  • 1ページから参加可能〜ページ上限なし（全体割合を鑑みて著しい偏りが発生する場合はご相談させていただきます）
  • アンソロジーのみを読んで内容が理解できる作品であること。前後編の前編のみなど、本誌外の作品の閲覧を前提とする内容は不可
  • カプ表記の有無は参加者様のご判断で構いません。表記なしでも問題ありません
  • 作品の冒頭には「作品タイトル」「作者名」を入れてください
  • 日本語以外の作品の応募も可能です。ただし誌面には翻訳版を掲載させていただきます。翻訳実施者や原語版原稿の取り扱いについては個別相談とさせてください
  • ページ始まりやフォントなどレイアウトに指定のある方はご連絡ください。ただし内容によってはお受けできない場合もございます
  • 編集の際に主催側でノンブルを追加します。原稿はノンブルのない状態で作成してください
  • 原稿提出方法などは応募確認後に別途ご案内いたします

漫画、イラスト（モノクロ）

  • 漫画は左ページ始まり
  • モノクロ2値 または グレースケール
  • 解像度：600dpi
  • 仕上がりサイズ：148×210mm
  • 原稿サイズ：154×216mm（上下左右3mmずつの塗り足しを加えたサイズ）
  • 提出形式：PSD
  • プリントオン様のA5サイズテンプレートをご使用ください
  • 完全データでのご提出をお願いします。データ作成に関してご不明な点がございましたらご連絡ください

小説、短歌 / 俳句 / 川柳

  • 小説は2段組
  • 提出形式：テキストファイル（.txt）
    テキストファイルでご提出後、主催で組んだものをチェックしていただきます。テキストファイルでの提出が難しい方はご相談ください
  • ルビ・傍点は以下のように指定
    〇ルビ：「漢字［よみ］ルビ」の形式で指定してください
    例：桜彩［さくらいろ］ルビは名曲だ。
    ※［ ］内がルビとなります
    〇傍点：傍点を付けたい文字を「【 】傍点」の形式で指定してください
    例：そんなに【大事】傍点なものなら、
    ※「【 】傍点」自体は組版時に削除し、対象文字に傍点を付けます

NG表現

  • キャラクターや作品イメージからの著しい逸脱
  • 対象となる2人以外のカップリング表現
  • SideM以外のキャラクターの登場（他アイドルマスターシリーズもNG）。候補生はOK
  • 公式イベント・ライブ等のレポート、感想、考察を主題とした記事・文章
  • 劇中劇含むパロディ
    原作時空のみ。原作時空でしたらモバエム、エムステ、サイスタ、ポータル、わけmini、アニメ、ミックスした時空、いずれも問題ありません。劇中劇に関してはモチーフにするなどでしたら同じく問題ありません
  • 猟奇表現
  • 成人向け表現
  • 性転換
  • トレースや剽窃
  • AI生成物を主体とした作品（アイデア出しや誤字チェックなどの局所的な使用であればOK）
  • 登場キャラクターの死を取り扱った作品
  • 社会啓発（例：防災、交通安全、健康等）や特定の主張・活動・プロジェクトのPR
  • 実在する企業名や商品名などの固有名詞、人物名（キャスト含む）の使用
  • キャストのやり取りを元にした作品
    プロミなど台本が存在するものはOKですが、ライブパートのアドリブなどを取り扱うのはNGとします
  • 公式画像、ゲーム内素材、ロゴ等の使用。その他公式作品と誤認されるような表現
  • 第三者の権利を侵害する表現
  • 差別的表現その他、特定の個人・集団を不当に攻撃する表現
  • 無理矢理・非同意を想起させる表現は、内容によってはお断りする場合があります。掲載可能と判断した場合も、わかりやすい位置へのゾーニング表記を必須とします
  • その他ゾーニングが必要そうな表現に関してはあらかじめご相談ください
  • 以上の規定に反していた方はご連絡させていただき、修正に応じていただけない場合は掲載を見送らせていただきます

参加にあたっての注意事項

  • 参加者間の批判・攻撃禁止
    アンソロを発端とした参加者間のトラブルが確認された場合、主催は双方への連絡・参加停止・参加取消等の対応を行います（有責を主催で判断した場合、新たなトラブルへつながる可能性があるため）。トラブルに繋がりそうな事案がありましたら反応をせず、まずは速やかに主催までご連絡ください。トラブルの内容によっては、必要に応じて適切な第三者機関への相談を検討します。
  • 寄稿作品に関して第三者との間で権利侵害等の問題が生じた場合、主催は合理的な範囲で対応します。寄稿作品の制作内容については、原則として寄稿者本人の責任においてご確認ください
  • 一度辞退された場合、原則として再参加はお受けできません
  • 企画内容や参加者情報の無断公開禁止
  • 本アンソロジーへの寄稿作品の個人誌・Web等への再録は、発刊日から1年経過後より可能です
  • 社会情勢によって企画の内容を変更する可能性があります。ご了承ください
